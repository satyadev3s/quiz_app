# QuizMaster – Interactive Quiz Platform

QuizMaster is an interactive web-based quiz application built using HTML, CSS, JavaScript, Flask, and SQLAlchemy.

Users can select a subject, answer questions, and view their score with animated UI effects.

---

## Live Demo

View the live project here:

https://quiz-gen-rx7b.onrender.com/

---

## Features

- Subject selection (Maths, Science, Biology, English)
- Interactive quiz interface
- Animated UI using GSAP
- Confetti celebration animation
- Progress bar tracking
- Score calculation
- Backend score storage
- Responsive design using Tailwind CSS

## Installation

Clone the repository

git clone https://github.com/yourusername/quizmaster.git

cd quizmaster

---

Create virtual environment

python -m venv venv

Activate environment

Windows:

venv\Scripts\activate

Linux / Mac:

source venv/bin/activate

---

Install dependencies

pip install -r requirements.txt

---

Run the project

python app.py

Open browser

http://127.0.0.1:5000
